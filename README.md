# MandoAI

واجهة ويب عربية ومتجاوبة للمحادثة مع نماذج GLM عبر خدمة `glm-ai.chat`، مبنية باستخدام FastAPI وواجهة HTML/CSS/JavaScript بسيطة.

## المزايا
- اختيار النموذج من قائمة نماذج GLM النصية.
- بث الردود تدريجيًا (SSE).
- حفظ سجل المحادثة واختيار النموذج محليًا في المتصفح.
- معالجة أخطاء الاتصال والمهلة والرفض من الخدمة.
- تنفيذ الاتصال الخارجي من الخادم بدل كشف تفاصيل الاتصال في المتصفح.
- واجهة عربية RTL متجاوبة.

## النماذج المتاحة
يعرض التطبيق نماذج GLM النصية فقط. لا يعرض موصلات أو نماذج الخدمات الخارجية الواردة في السكربتات التجريبية.

## التشغيل
يتطلب Python 3.10 أو أحدث:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`.

## النشر
شغّل الأمر التالي على منصة استضافة Python:

```bash
uvicorn app:app --host 0.0.0.0 --port ${PORT:-8000}
```

## ملاحظات
- يعتمد التطبيق على خدمة خارجية قد تغيّر واجهتها أو تفرض حدود استخدام.
- لا توجد مفاتيح API أو بيانات دخول مضمنة في المستودع.
- لم يتم تأكيد الاتصال الحي بالخدمة؛ يلزم اختبار النشر الفعلي للتحقق من توفر النماذج.


## النشر على Railway
1. افتح Railway وأنشئ مشروعًا جديدًا باستخدام Deploy from GitHub Repo.
2. اختر المستودع `mahamednagyteam-star/MandoAI` والفرع `main`.
3. سيستخدم Railway ملف `Dockerfile` وإعدادات `railway.json` تلقائيًا.
4. بعد نجاح النشر، افتح النطاق العام الذي يوفره Railway واختبر `/api/health`.

مسار فحص الصحة: `/api/health`. لا يحتاج التطبيق إلى متغيرات سرية خاصة به حاليًا. يعتمد إرسال المحادثات على توفر الخدمة الخارجية `glm-ai.chat`.

## الاختبارات
يحتوي المستودع على اختبارات أساسية يتم تشغيلها تلقائيًا عبر GitHub Actions عند كل تحديث للفرع `main`.

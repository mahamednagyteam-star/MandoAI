# MandoAI

واجهة ويب عربية ومتجاوبة للمحادثة مع نماذج GLM عبر خدمة `glm-ai.chat`، مبنية باستخدام FastAPI وواجهة HTML/CSS/JavaScript بسيطة.

## المزايا
- اختيار النموذج من قائمة نماذج GLM النصية.
- بث الردود تدريجيًا (SSE).
- حفظ سجل المحادثة واختيار النموذج محليًا في المتصفح.
- معالجة أخطاء الاتصال والمهلة والرفض من الخدمة.
- تنفيذ الاتصال الخارجي من الخادم بدل كشف تفاصيل الاتصال في المتصفح.
- واجهة عربية RTL متجاوبة.

## النماذج المدرجة
`glm-5.3`, `glm-5.3-flash`, `glm-5.2`, `glm-5.1`, `glm-4.7`, `glm-4.6`, `glm-4.5`, `glm-4.7-flash`, `glm-4.5-flash`, `glm-4.7-flashx`, `glm-image`.

إدراج اسم النموذج لا يضمن أن الخدمة الخارجية تتيحه حاليًا. خيار `glm-image` توضيحي فقط؛ مسار الصور في السكربت الأصلي كان معطّلًا ولم يتم التحقق من واجهته، لذلك لا يدّعي التطبيق دعمه.

## التشغيل
يتطلب Python 3.10 أو أحدث:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`.

## النشر
شغّل الأمر التالي على منصة استضافة Python:

```bash
uvicorn app:app --host 0.0.0.0 --port ${PORT:-8000}
```

## ملاحظات
- يعتمد التطبيق على خدمة خارجية قد تغيّر واجهتها أو تفرض حدود استخدام.
- لا توجد مفاتيح API أو بيانات دخول مضمنة في المستودع.
- لم يتم تأكيد الاتصال الحي بالخدمة؛ يلزم اختبار النشر الفعلي للتحقق من توفر النماذج.
